# Relationer mellan ISO, bländare och slutartid

## Kort förklaring

ISO, bländare och slutartid kan balansera bildens ljushet, men varje inställning har sin egen visuella konsekvens.

## Bländare och slutartid

Bländare och slutartid påverkar båda den fysiska mängden ljus på sensorn. Om bländaren släpper in ett stop mindre ljus kan slutartiden göras ett stop längre för att ge liknande fysisk exponering.

Exempel:

- f/2.8 och 1/250
- f/4 och 1/125

Dessa kan ge liknande ljusmängd, men f/4 ger större skärpedjup och 1/125 ger mer risk för rörelseoskärpa.

## Bländare och ISO

Om bländaren stängs ner blir bilden fysiskt mörkare. ISO kan höjas för att göra resultatet ljusare, men den fysiska exponeringen är fortfarande lägre.

Exempel:

- f/2.8, ISO 100
- f/4, ISO 200

Ljuset i slutbilden kan kännas liknande, men f/4 ger större skärpedjup och ISO 200 kan ge något mer brus.

## Slutartid och ISO

Om slutartiden görs snabbare fångas mindre ljus. ISO kan höjas för att behålla bildens ljushet.

Exempel:

- 1/250, ISO 100
- 1/1000, ISO 400

Resultatet kan kännas lika ljust, men 1/1000 fryser rörelse bättre och ISO 400 kan ge mer brus.

## Kreativa prioriteringar

Välj först den inställning som styr bildens viktigaste uttryck. För porträtt är det ofta bländare. För sport är det ofta slutartid. ISO används ofta för att få kombinationen att fungera i det ljus som finns.

## Exponeringskompensation i stops

En ändring som gör bilden mörkare med ett stop kan balanseras av en annan ändring som gör bilden ljusare med ett stop.

Exempel:

- f/2.8 -> f/4 = -1 stop
- 1/250 -> 1/125 = +1 stop
- ISO 100 -> ISO 200 = +1 stop i bearbetad ljushet

## Begränsningar

Samma ljushet betyder inte samma bild. Skärpedjup, rörelseoskärpa, brus, dynamiskt omfång och highlight-bevarande kan förändras även när bilden ser lika ljus ut.

## Vanliga missförstånd

- "Om bilden är lika ljus är inställningarna likvärdiga." De kan vara likvärdiga i ljushet men inte i uttryck.
- "ISO kan ersätta ljus." ISO kan göra signalen ljusare, men det ersätter inte informationen som mer ljus hade gett.
